## [7.0.0-beta.1] - 2026-0X-XX

### Added
- **Initial Public Release**: Cross-platform GUI application (Tauri v2) for converting SpriteStudio projects (`.sspj`) to `.ssab` binaries.
- **Conversion**: Single-file and batch (folder) conversion with drag & drop, an asset-embedding option, conversion history, and real-time logs.
- **Distribution**: Portable builds — Windows `.zip` (portable exe) and macOS universal `.app.tar.gz` (signed & notarized).
- **Documentation**: Bilingual (EN/JA) README and MkDocs site.
