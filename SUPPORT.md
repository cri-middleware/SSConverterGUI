# Support Guide

Thank you for using SSConverter GUI! We want to ensure you have the best experience possible. Please use the following channels to get help, report issues, or suggest improvements.

## 🛠️ GitHub Issues (Public)
For Bug Reports and Feature Requests, please use [GitHub Issues](https://github.com/cri-middleware/SSConverterGUI/issues). This is the best place for:
- **Bug Reports**: If you've found a problem in the application (e.g. file selection, UI glitches).
- **Feature Requests**: If you have ideas for new features or improvements.

*Note: Please do NOT use GitHub Issues for questions about how to use the application. See the sections below.*

Before opening a new issue, please search existing issues to see if your topic has already been discussed.

**Is it a GUI issue or a conversion issue?** If the problem is in the conversion itself (e.g. incorrect binary output, a crash while converting a `.sspj`), it belongs to the conversion engine — please report it to the [SpriteStudio-SDK](https://github.com/cri-middleware/SpriteStudio-SDK) repository instead.

## ❓ Questions on How to Use the App
If you have questions about how to use the application, need advice, or want to share tips with other developers, please use our official community forum:

👉 [**SpriteStudio Community**](https://spritestudio.jp/community/)

## 🔒 Private Inquiries & Data Submission
For private consultations, sensitive issue reports, or support with contractual guarantees, please use our official inquiry form:

👉 [**CRI Middleware Inquiry Form (English)**](https://www.webtech.co.jp/contact/en.html)

*Note: the English form has no file upload. To send large reproduction data (e.g., a `.sspj` project), use the [Japanese Help Center form](https://www.webtech.co.jp/help/ja/spritestudio7/inquiries/ssplayer_tool/), which takes a zip of up to 8 MB.*

## 🛡️ Security Vulnerabilities
Please do **not** report security vulnerabilities through public GitHub Issues. See [SECURITY.md](./SECURITY.md) for the private reporting channels.

## 日本語でのサポート (Support in Japanese)

SSConverter GUI をご利用いただきありがとうございます。ご質問や不具合の報告は、以下の窓口をご利用ください。

### 🛠️ GitHub Issues (公開)
不具合のご報告や新機能のご要望は [GitHub Issues](https://github.com/cri-middleware/SSConverterGUI/issues) へ投稿してください。
- **不具合**: アプリの動作に問題がある場合（ファイル選択、UI 崩れ等）。
- **要望**: 新機能や改善のアイデアがある場合。

*注: アプリの使い方に関するご質問は、GitHub Issues では受け付けておりません。以下の窓口をご利用ください。*

投稿前に、同様の内容が既に報告されていないか、既存の Issue を検索してください。

**GUI の問題か、変換の問題か:** 変換処理自体の問題（出力バイナリがおかしい、`.sspj` の変換中にクラッシュする等）は変換エンジン側の課題です。[SpriteStudio-SDK](https://github.com/cri-middleware/SpriteStudio-SDK) リポジトリへご報告ください。

### ❓ 使い方のご質問
アプリの使い方に関するご質問、相談、または他の開発者との情報共有には、公式コミュニティをご利用ください。

👉 [**SpriteStudio コミュニティ**](https://spritestudio.jp/community/)

### 🔒 個別のお問い合わせ・データの送付
非公開でのご相談、再現データ（`.sspj` プロジェクトなど）を送付いただく必要がある場合、または契約に基づくサポートが必要な場合は、公式の**ヘルプセンター**をご利用ください。

👉 [**ヘルプセンター（お問い合わせフォーム）**](https://www.webtech.co.jp/help/ja/spritestudio7/inquiries/ssplayer_tool/)

### 🛡️ 脆弱性のご報告
セキュリティ上の脆弱性は、公開の GitHub Issues では**報告しないでください**。非公開の報告窓口については [SECURITY.md](./SECURITY.md) を参照してください。
