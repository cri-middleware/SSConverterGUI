# Installation

This page is for users who want to run the finished application. It requires no command-line
knowledge. If you want to build from source instead, see [Development](development.md).

## Download

1. Download the latest executable for your OS from the
   [GitHub Releases](https://github.com/cri-middleware/SsConverterGUI/releases) page.
2. Run the downloaded file to launch the application (no installation required for portable
   versions).

Once the application starts, continue to [Usage](usage.md).
