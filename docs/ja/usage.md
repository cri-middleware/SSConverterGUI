# ▶️ 使い方

このページでは、変換作業の一連の流れを説明します。アプリケーションをまだ導入していない場合は、[インストール](install.md)を参照してください。

## プロジェクトを変換する

1. アプリケーションを起動します。
2. **"📥 Target .sspj File or Folder"** エリアに、`.sspj` ファイル、または複数の `.sspj` ファイルを含むフォルダをドラッグ＆ドロップします。（または **「File...」**「**Folder...**」ボタンからブラウズして選択します）1 回のドロップで扱えるのは 1 つだけです。枠線がドロップ先を示し、2 つ目以降はログに出したうえで無視します。
3. *(オプション)* **"📤 Output"** の行で出力先フォルダを変更します（**「Change...」** から、またはこの行にフォルダをドロップして）。この行には出力先が表示されます。そのままにした場合は、元の `.sspj` と同じ場所の `<名前>/` フォルダに出力されます。手順 4 にチェックを入れた場合は `<名前>_emb/` となり、埋め込み版が通常版を上書きすることはありません。ここで選んだフォルダは次に選ぶプロジェクトにも引き継がれるので、一度指定すれば複数を続けて変換できます。既定に戻すには、選んだあとに現れる **「Reset」** を押します。選んだフォルダには `<名前>/` フォルダを作らずにファイルを直接書き出すので、同じ名前のファイルがすでにあれば上書きされます（同じプロジェクトの埋め込み版や、別のプロジェクトの同じ名前のテクスチャ・アニメパック）。手順 2 でフォルダを選ぶと、指定は消えてこの行は無効になります。一括変換は各プロジェクトを自分の `.sspj` の隣に出力するため、指定できる出力先が 1 つに決まらないからです。
4. *(オプション)* アセット（画像等）をバイナリファイルに埋め込みたい場合は、**"Embedded Assets"** にチェックを入れます。
5. **"⚡ Convert"** ボタンをクリックして、変換処理を開始します。
6. 実行中は、ログの上のバーが `12 / 50` のように進み具合を示します。問題なく終わるとダイアログは閉じ、ボタン横のバッジが `Success` になり、その隣に **「📂 Reveal Output」** が現れます。読むべきことがある場合（プロジェクトの失敗、途中で打ち切られたスキャン、実行を始められなかったとき）は、ダイアログが残って**結果**に切り替わります。見出しで何が起きたかを伝え、失敗したプロジェクトはフルパスとコンバーターの理由つきで一覧され、打ち切られたスキャンは警告として並びます。**「📂 Reveal Output」** は変換先のフォルダを開きます。1 件ならそのフォルダを、一括なら選択したフォルダを開きます（一括は出力が各 `.sspj` の隣に散るためです）。**「Close」** か Esc で結果を閉じても、ボタン横のバッジとボタンは残ります。**「Stop / Cancel」** は実行中のファイルで実行を止め、結果を出さずにダイアログを閉じます。バッジにはどこまで進んだか（`Cancelled (29 / 50)`）が出ます。止める前に終わった分は残り、1 件でも変換できていれば **「📂 Reveal Output」** で開けて、履歴にも記録されます。

出力したフォルダを、お使いの Player がアセットを読み込む場所へコピーします。どこに置くかは各 Player のクイックスタートにあります。[プラットフォームの選び方](https://cri-middleware.github.io/SpriteStudio-Docs/ja/overview/choose-your-platform/)から辿れます。

## 一括変換

手順 2 でフォルダを選択すると、その中に含まれる `.sspj` ファイルをまとめて変換できます。ファイルを
1 つずつ追加する必要はありません。

## 変換履歴

1 回の実行につき **1 件**、選択したもの（単体なら `.sspj`、一括ならフォルダ）で記録されます。再実行すると、そのときの設定のまま繰り返せるので、入力・出力を選び直す必要はありません。パスの下の行に、その設定と最後に実行した日時が出ます。**「Clear History」** は確認のうえですべての履歴を消します。消した履歴は元に戻せません。

## キーボード

| キー（Windows / macOS） | 動作 |
|---|---|
| `Ctrl+O` / `⌘O` | `.sspj` を選びます（**「File...」** と同じ） |
| `Ctrl+Shift+O` / `⇧⌘O` | フォルダを選びます（**「Folder...」** と同じ） |
| `Ctrl+Enter` / `⌘Enter` | 変換します |

入力を選ぶと **「Convert」** にフォーカスが移るので、そのまま Enter で変換を始められます。実行中は進捗ダイアログがキーボードを受け持ち、Tab はダイアログの中だけを巡ります。Esc では実行は止まらないので、止めるときは **「Stop / Cancel」** を使ってください。結果が出ているときは、Esc で **「Close」** と同じく閉じられます。

## 外観

右上のボタンでテーマを切り替えます。既定ではシステムのライト／ダーク設定に従います。クリックするたびに、ライト、ダーク、システムに従う、の順に切り替わり、アイコンが今の設定を示します（🖥️ システム、☀️ ライト、🌙 ダーク）。選んだ設定は記憶されます。
