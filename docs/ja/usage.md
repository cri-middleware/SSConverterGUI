# ▶️ 使い方

このページでは、変換作業の一連の流れを説明します。アプリケーションをまだ導入していない場合は、
[インストール](install.md)を参照してください。

## プロジェクトを変換する

1. アプリケーションを起動します。
2. **"📥 Target .sspj File or Folder"** エリアに、`.sspj` ファイル、または複数の `.sspj` ファイルを
   含むフォルダをドラッグ＆ドロップします。（または **「File...」**「**Folder...**」ボタンからブラウズ
   して選択します）1 回のドロップで扱えるのは 1 つだけです。枠線がドロップ先を示し、2 つ目以降は
   ログに出したうえで無視します。
3. *(オプション)* **"📤 Output Directory"** で出力先フォルダを指定します（**「Browse...」** から、
   またはこのエリアにフォルダをドロップして）。空欄のままにした場合、元の
   `.sspj` と同じ場所の `<名前>/` フォルダに出力されます。手順 4 にチェックを入れた場合は
   `<名前>_emb/` となり、埋め込み版が通常版を上書きすることはありません。実際に使われるフォルダは
   入力欄のプレースホルダに表示されます。
4. *(オプション)* アセット（画像等）をバイナリファイルに埋め込みたい場合は、**"Embedded Assets"** に
   チェックを入れます。
5. **"⚡ Convert"** ボタンをクリックして、変換処理を開始します。
6. ボタン横のバッジにステータスが、その下のログに 1 件ごとの結果が出ます。

## 一括変換

手順 2 でフォルダを選択すると、その中に含まれる `.sspj` ファイルをまとめて変換できます。ファイルを
1 つずつ追加する必要はありません。

## 変換履歴

過去の変換は履歴に保存されるため、入力・出力を選び直さなくても、同じ設定で素早く再実行できます。
