# ▶️ 使い方

このページでは、変換作業の一連の流れを説明します。アプリケーションをまだ導入していない場合は、[インストール](install.md)を参照してください。

## プロジェクトを変換する

1. アプリケーションを起動します。
2. **"📥 Target .sspj File or Folder"** エリアに、`.sspj` ファイル、または複数の `.sspj` ファイルを含むフォルダをドラッグ＆ドロップします。（または **「File...」**「**Folder...**」ボタンからブラウズして選択します）1 回のドロップで扱えるのは 1 つだけです。枠線がドロップ先を示し、2 つ目以降はログに出したうえで無視します。
3. *(オプション)* **"📤 Output Directory"** で出力先フォルダを指定します（**「Browse...」** から、またはこのエリアにフォルダをドロップして）。空欄のままにした場合、元の
   `.sspj` と同じ場所の `<名前>/` フォルダに出力されます。手順 4 にチェックを入れた場合は
   `<名前>_emb/` となり、埋め込み版が通常版を上書きすることはありません。実際に使われるフォルダは入力欄のプレースホルダに表示されます。手順 2 でフォルダを選ぶとこのエリアは無効になります。一括変換は各プロジェクトを自分の `.sspj` の隣に出力するため、指定できる出力先が 1 つに決まらないからです。
4. *(オプション)* アセット（画像等）をバイナリファイルに埋め込みたい場合は、**"Embedded Assets"** にチェックを入れます。
5. **"⚡ Convert"** ボタンをクリックして、変換処理を開始します。
6. 実行中は、ログの上のバーが `12 / 50` のように進み具合を示します。完了するとウィンドウが**結果**に切り替わり、見出しで何が起きたかを伝え、失敗したプロジェクトはフルパスとコンバーターの理由つきで一覧されます。途中で打ち切られたスキャンは警告として並びます。**「📂 Reveal Output」** は変換先のフォルダを開きます。1 件ならそのフォルダを、一括なら選択したフォルダを開きます（一括は出力が各 `.sspj` の隣に散るためです）。**「Close」** か Esc で結果を閉じても、ボタン横のバッジにステータスが残り、**「📂 Reveal Output」** もそこに残ります。**「Stop / Cancel」** で止めた場合は結果を出さず、バッジが `Cancelled` になるだけです。

## 一括変換

手順 2 でフォルダを選択すると、その中に含まれる `.sspj` ファイルをまとめて変換できます。ファイルを
1 つずつ追加する必要はありません。

## 変換履歴

1 回の実行につき **1 件**、選択したもの（単体なら `.sspj`、一括ならフォルダ）で記録されます。再実行すると、そのときの設定のまま繰り返せるので、入力・出力を選び直す必要はありません。パスの下の行に、その設定と最後に実行した日時が出ます。

## 外観

右上のボタンでテーマを切り替えます。既定ではシステムのライト／ダーク設定に従います。クリックするたびに、ライト、ダーク、システムに従う、の順に切り替わり、アイコンが今の設定を示します（🖥️ システム、☀️ ライト、🌙 ダーク）。選んだ設定は記憶されます。
